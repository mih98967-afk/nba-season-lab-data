# v6.19 — schedule context / conservative calendar UX

Unknown previous games are not labelled rested. Opponent difficulty is deliberately **not scored** because it is not yet validated against fantasy outcomes. Original Optimizer, team/transfer/score models, personal data and Firebase wiring unchanged.
