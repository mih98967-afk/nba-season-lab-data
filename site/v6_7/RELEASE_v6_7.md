# NBA Season Lab v6.7 — безопасная регистрация прошлых замен

Дата релиза: 2026-10-26. Продолжение опубликованной пользователем v6.6.

## Изменения

В разделе «Замены» добавлен блок «Уже сделал замены на Sports.ru?»:

1. Ввод от 1 до 12 *уже исполненных* замен с фактическим временем по Москве, проданным и купленным игроком, ценой продажи и ценой покупки на момент операции.
2. Полный read-only replay исторической десятки `initialRoster` и журнала `executed` до каждой операции, включая ранее записанные и вставляемые задним числом.
3. Проверка полной десятки (2 на позицию), отсутствия двойного владения игроком, бюджета каждого шага, недельного лимита трёх замен, порядка операций и повторных покупок.
4. Не производится ни одной записи до предварительного просмотра и отдельного подтверждения; перед изменением автоматически создаётся загрузка полной резервной копии личного профиля на устройство.
5. Реальная касса после вставки = текущая касса + сумма всех новых (продажа − покупка), существующие операции и цены сохраняются.
6. Отказ от исторической вставки, если не совпадает восстановленная и сохранённая текущая десятка, есть активный черновик, нарушена последовательность или другая проверка.
7. Итоговая десятка и касса на момент введения совпадают с последовательным replay. Пересчёт Sports.ru FP по историческому составу применит `ownedAt()` — старый механизм не менялся.

## Ограничения честности

- Это учёт выполненных операций, а НЕ отправка трансферов на Sports.ru.
- Историческая касса вычисляется из текущего сохранённого остатка. Если пользователь вручную правил кассу до импорта, промежуточные суммы могут быть неисторическими. Сверка фактического текущего остатка обязательна.
- Историческая принадлежность игрока клубу и время разблокировки в Sports.ru не могут быть точно восстановлены из текущего NBA-каталога; в результате показывается предупреждение. Лимит 2 из клуба строго проверяется в итоговой текущей десятке.
- Подсчёт 3 замен по неделям Пн–Вс МСК сохраняет прежнюю семантику guard v6.6; возможный иной момент сброса квоты около понедельника 15:00 отмечается предупреждением.
- Скачивание резервной копии зависит от настроек браузера. Дополнительно можно экспортировать её вручную в профиле.
- Приложение не знает текущих операций/цен Sports.ru и НЕ исправляет их без пользовательского подтверждения.
- Cloud save Firebase вызывается через прежний пользовательский документ, личные данные не сохраняются в публичном GitHub.
- Изменений исследовательских моделей, данных NBA, Firebase security rules, цен автоматически, GitHub `data/schedule.json` нет.

## Публикация

1. Скачать единственный файл `NBA_Season_Lab_v6_7_History_Backfill.zip`.
2. Загрузить в существующий Firebase Cloud Shell проекта `nba-season-lab`.
3. Одна команда `unzip -qo ~/NBA_Season_Lab_v6_7_History_Backfill.zip -d ~ && cd ~/nba-season-lab-deploy && firebase deploy --only hosting --project nba-season-lab`.
4. Сайт обновится только после ручного `firebase deploy`. Новая версия не публикуется автоматически. При отсутствии ошибки проверить «Замены» → «Уже сделал замены на Sports.ru?».

Никаких платных сервисов, Lovable или Blaze. Никаких новых проектов и приватных GitHub-записей.
