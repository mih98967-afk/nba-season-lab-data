## Сравнение с точной прежней формулой сайта

ВNodeVM исполнены неизменённые функции PR175: обновление команды из LIVE,
история сыгранных матчей, seed mean + decay.87 последних8, участие,
точный свежий официальный OUT. Те же функции в PR176 побайтно идентичны.
Использованы сохранённые LIVE до выдачи каждой заморозки, исходный публичный
base, последние опубликованные до выдачи official feeds и высокая уникальная
identity. Режимы current/baseline, без частных ручных override. Это честный
восстановленный replay после исходов; старая формула не была отдельным
заранее замороженным прогнозом. Частный фактический сценарий владельца не
воспроизводился.

Исключение четырёх независимо обнаруженных загрязнённых seed-историй

## Воспроизведение и хранение

Код и агрегированные отчёты предназначены существующему research draft.
Необходимые исходные байты/большие построчные результаты хранятся в научном
checkpoint с исходными относительными путями. Здесь нет приватного каталога.
`NBA_RESEARCH_BASE` задаёт исходный research_base;
`NBA_CODE_ROOT` — корень существующего репозитория сsrc. Перед запуском
сравнения нужно восстановить сохранённые baseline_inputs и frozen файлы из
checkpoint, без повторной загрузки изменяемых источников.
