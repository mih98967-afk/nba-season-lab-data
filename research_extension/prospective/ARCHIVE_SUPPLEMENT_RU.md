# Дополнительная проверка исходных frozen-прогнозов по NBA ID

Свежие NBA-derived архивы SportsDataverse, полученные 17 ноября, позволяют оценить ту же первоначальную выборку без обязательного сопоставления с fantasy-каталогом. Исходные 1741 прогноза, baseline и прежний ESPN-only отчёт не изменялись. Код использует сохранённый `current_validation.load_current_combined` с датой отсечки 17 ноября и проверяет хэши новых источников.

## Полнота и разные типы неопределённости

По-прежнему завершились только **8 матчей / одна NBA-дата / 261 уникальный player-game**.

- **Участие известно для 259 из 261**: 179 сыграли, 80 имеют явный DNP/inactive. Два отсутствующих в точном архивном player-game соединении остаются UNKNOWN.
- **FP разрешены для 255**: 175 сыгранных + 80 явных пропусков. Ещё у четырёх сыгравших расходятся статистические компоненты ESPN и NBA-derived архива. Их FP исключены из расчёта ошибок, но подтверждённое участие сохранено в отдельной оценке P(play).
- **1219 long-lead прогнозов всё ещё FUTURE**. Дублирование near_primary и interval_challenger не увеличивает независимую выборку.

## Результаты исходной near_primary модели

| Метрика | Baseline | Frozen candidate | Знаменатель |
|---|---:|---:|---|
| FP MAE при выходе | 6.80645 | 6.85096 | 175 согласованных played FP |
| FP RMSE при выходе | 8.62720 | 8.58518 | те же 175 |
| Brier P(play) | 0.15531 | 0.08589 | 259 известных участий |
| Log loss P(play) | 0.47135 | 0.26914 | те же 259 |
| MAE с учётом пропусков | 6.18528 | 5.32418 | 255 разрешённых FP |

**Условный MAE FP в эту ночь у кандидата немного хуже baseline**, хотя RMSE немного лучше. Значительная часть улучшения общей ошибки связана с моделью участия, а не с более точными FP при выходе.

При любых двух неизвестных исходах участия paired Brier gain остаётся в диапазоне **[0.06841; 0.07017]** на этой конкретной ночи. Это границы по отсутствующим меткам, **не доверительный интервал** и не доказательство сохранения преимущества в будущем.

## Прогнозные интервалы

| Номинал | Покрытие при выходе, n=175 | Покрытие с пропусками, n=255 |

| 50% | 48.00% | 59.22% |
| 80% | 77.14% | 82.35% |

Разные знаменатели существенны. Безусловные интервалы включают вероятность нулевого результата при пропуске, поэтому их покрытие может быть консервативным из-за массы в нуле. Одна дата не даёт устойчивой оценки калибровки или основания подстраивать интервалы под эту ночь.

Два неразрешённых player-game: Tristan Enaruna / Cleveland и Enrique Freeman / Minnesota. Отсутствие точной строки не превращено в DNP.

## Доказательность и воспроизведение

Это **послематчевые NBA-derived архивы SportsDataverse**, а не прямое подтверждение Sports.ru credited FP. Архив может включать статистические исправления. Точный NBA game ID, ET date, команды и NBA person ID проверены; источник не содержит UTC tipoff, поэтому новые исторические UTC-времена не заявляются.

```bash
NBA_RESEARCH_BASE=/absolute/path/to/research_base python3 research_extension/prospective/score_archive.py
python3 -m unittest discover -s research_extension/prospective -p 'test_score_archive.py' -v
```

Файлы: `results/ARCHIVE_AUGMENTED_REPORT.json`, `results/archive_augmented_scored_records.json`, `results/FP_SOURCE_DISAGREEMENTS.json`. Новый scorer прошёл **8/8 целевых тестов**. У модели по-прежнему `adopt_on_site=false`; реальные выигрыши KEEP/NOW/LATER не проверены.
